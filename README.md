Backend Project

This project is a backend-only clone inspired by YouTube.
It was built as my project during backend learning to practice real-world backend concepts such as authentication, media handling, and API design.

Features

User registration & login (Auth system)

JWT-based authentication

Upload & manage videos

Like / Comment system

User profile & channel features

Video data storage & retrieval

REST API structure

Tech Stack

Node.js

Express.js

MongoDB / Mongoose

JWT authentication

Multer / Cloudinary(cloud)



Purpose

To practice and understand backend development by building a real-world style project similar to a video platform backend.
